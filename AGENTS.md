# Работа с историей чата

- По запросу пользователя хранить Markdown-историю текущего чата в `docs/chat-history/`.
- Перед сжатием контекста, если есть возможность выполнить инструменты, запускать `docs/chat-history/export-chat.py`, чтобы дописать отсутствующие сообщения из журнала сессии.
- Также обновлять историю перед завершением следующих рабочих ответов: это уменьшает потери, если сжатие произойдёт без предварительного уведомления. Итоговый ответ текущего хода попадёт в журнал при следующем запуске экспорта.
- Использовать существующий файл этого чата, дописывать только отсутствующие записи; не переписывать исторические решения и не удалять повторы, если они были отдельными сообщениями.
- Экспортировать сообщения пользователя, публичные ответы/промежуточные сообщения ассистента и вопросы/ответы интерактивных уточнений. Не экспортировать system/developer instructions, внутренние рассуждения, технические вставки окружения и сырые результаты инструментов.
- Скрипт относится к чату `01a186f9-adb9-7f93-ae71-0bc99f2441e6`. Для другого чата передать его JSONL через `--source` и отдельный путь Markdown через `--output`.
- Это инструкция агенту, а не установленный автоматический hook сжатия. Не заявлять, что обновление гарантированно выполняется при сжатии без возможности запуска инструментов.

Команда в этой Windows-среде:

```powershell
& 'C:\Users\admin\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' docs/chat-history/export-chat.py
```
